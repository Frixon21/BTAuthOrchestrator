    Settings

    Tokens are kept in this browser tab's session storage until the tab closes. They are never shown unless you choose Show.

    User-admin token

    LOCAL_USER_ADMIN_TOKEN. Sent only with user list, view, change and delete requests.

    Not set

    Emergency token

    EMERGENCY_ROTATION_TOKEN. Sent only with the emergency key rotation request.

    Not set

    Acting as

    Optional label sent as actedBy with user changes and as triggeredBy with key rotation. It is self-asserted and not verified. New users are always recorded as public registration.

    Forget all

    Removes both tokens and the acting-as label from this tab. Use this before leaving a shared computer.

    New user

    Creation uses the public registration endpoint. It works only while ALLOW_NEW_LOCAL_LOGIN_CREATION=true, and while that setting is on, anyone who can reach the service can create an account.

    3 to 64 characters: a-z, 0-9, dot, hyphen or underscore. Stored in lowercase.

    Delete user

    This permanently deletes the user . It cannot be undone. Audit history is kept.

    Rotate the signing key?

    The current signing key is revoked and a new key is created. Every session signed with the current key stops working immediately for any verifier that fetches a fresh JWKS. Users must sign in again.
